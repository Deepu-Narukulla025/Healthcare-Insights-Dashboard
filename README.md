# Healthcare-Insights-Dashboard

## 📌 Overview  
This project analyzes healthcare data using Excel to derive key insights. It includes data cleaning, pivot table analysis, and interactive visualizations.  

## 📊 Key Features  
- **Data Cleaning:** Handling duplicates, missing values, and categorization.  
- **Interactive Dashboard:** Slicers, filters, and dynamic charts.  
- **Medical Insights:** Patient trends, admission analysis, and condition distribution.  
- **Advanced Excel Functions:** Pivot tables and conditional formatting.  

## 🛠️ Tools Used  
- Microsoft Excel  
- Pivot Tables & Charts  
- Data Validation & Conditional Formatting  

## 📈 Key Achievements  
- Cleaned & structured **55,000+ records**, reducing inconsistencies by **95%**.  
- Developed an interactive dashboard improving **data accessibility by 70%**.  
- Automated insights using pivot tables & slicers, increasing analysis efficiency by **60%**.  
- Categorized billing data for better financial analysis, enhancing reporting by **40%**.  

## 📂 Project Files  
- `Healthcare Insights Dashboard.xlsx` – Main dashboard  
- `Data Cleaning Steps.txt` – Preprocessing details  

## 🚀 How to Use  
1. Open `Healthcare Insights Dashboard.xlsx`  
2. Explore insights using slicers & filters  
3. Modify pivot tables for customized reports
